# MAmr9UH.github.io

Personal academic website of Amr Mohamed.

## Put it online
1. Create a public GitHub repo named exactly `MAmr9UH.github.io`.
2. Upload every file and folder here (keep the folder structure).
3. Settings → Pages → Source: `main` branch, `/ (root)` → Save.
4. Live at https://MAmr9UH.github.io within ~1 minute.

## Replace the placeholders
| Placeholder | Replace with | Where to edit |
|---|---|---|
| images/profile.svg | your photo (profile.jpg, square) | index.html, `<img src=...>` in hero |
| images/papers/*.svg | paper figure or GIF | index.html, Publications |
| images/projects/*.svg | project images | index.html, project cards |
| `href="#"` buttons | GitHub / Kaggle / PDF / Scholar links | index.html |
| "Video coming soon" | YouTube embeds | teaching.html (instructions in comment) |

Tip: for animated figures, an `.mp4` is ~10x smaller than a `.gif`:
`<video src="images/papers/naps.mp4" autoplay loop muted playsinline></video>`
